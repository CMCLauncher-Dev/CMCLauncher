测试更新说明（2026-11-14）

本次修复
1. Forge / NeoForge 安装前，通过启动器下载并校验安装器声明的依赖，复用已有缓存、代理及下载源设置，减少 Java 安装器反复连接失败。
2. NeoForge 增加官方 ForgeCDN 备用地址。安装器及其子 Java 进程跟随系统代理、直连或手动 HTTP / SOCKS5 代理设置，不修改系统代理，不关闭 Java 证书验证。
3. 安装器下载遇到连接中断时有限重试；校验失败、访问被拒绝及取消操作不会无限重试。
4. 安装失败时优先显示网络原因，避免只显示一长串缺失依赖名称。正常取消 GPU 采样改为 DEBUG 日志。

近期功能一起测试
1. Java 下载包包含多个 java.exe 时，正确选择外层 JDK，不再报 Sequence contains more than one element。
2. 个性化设置新增细灰色滚动条开关，支持即时切换及主题预设保存。
3. 修复受限目录中的文件选择、日志及配置目录回退；补充 macOS Intel / Apple Silicon 构建与 Java 路径识别。

建议测试顺序
1. 配置可用的本地 HTTP 代理，再安装日志中失败的 Minecraft 1.21.1 / NeoForge 整合包。
2. 重复安装，检查已校验的依赖是否复用；在准备依赖时取消，确认不留下可启动的半成品实例。
3. 分别测试系统代理、直连和手动 SOCKS5。Java 安装器暂不支持直接使用带认证或 HTTPS 端点的代理，会明确提示改用本地 HTTP / SOCKS5 代理。
4. 下载 Java 8，切换滚动条设置，检查设置保存及再次启动后的效果。

说明
日志中的大量 Connection reset / Connect timed out 属于安装器网络连接失败；本次修复不能保证外部服务器、网络或代理始终可用。macOS 的实际游戏启动与图形交互仍需在对应设备上验证。
