# About-page images

The about page uses local images, so opening it does not contact avatar servers.

- `ctoy.png` and `fuzhu.png`: GitHub avatars for `com-in` and `fuzhulike`, matched against the repository's public contributor list.
- `dotnet.png`, `winui.png`, `avalonia.png`, `anglesharp.png`: upstream GitHub organization avatars for `dotnet`, `microsoft`, `AvaloniaUI` and `AngleSharp`.
- `bmclapi.png`: the GitHub avatar of BMCLAPI author `bangbang93`.
- `terracotta.png`: the icon from the unmodified official Terracotta v0.4.2 Windows executable. Terracotta is © burningtnt; see [the integration notes](TERRACOTTA.md).
- `frp.png`: [GitHub's mark](https://github.githubassets.com/images/modules/logos_page/GitHub-Mark.png), used as a source-repository icon for projects without a packaged logo, including frp and Markdig.

Names, avatars and project marks belong to their respective owners. Each card links to its upstream project or contributor profile. These images are not required for downloading or running the optional clients.
