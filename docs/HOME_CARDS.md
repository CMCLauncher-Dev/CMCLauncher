# Home cards

Use the home page's customize button to edit its layout. Drag a card by its grip and drop it before or after another card. Arrow buttons remain available for keyboard use. Width and height choices are preserved when a card moves, and changes are saved to launcher settings.

**Add cards** opens a drawer containing only missing optional cards. Click one to append it, or drag it onto a position in the home layout. Cancelling a drag leaves the layout unchanged. The drawer reuses the existing overlay, Escape key and close button; it does not alter resource filters.

The account card shows six evenly spaced icon buttons in one centered row at Standard and Spacious heights: skin, cape, player name, account refresh, account management and code redemption. Descriptions appear in tooltips and accessibility names. Minecraft profile and redemption actions open the official website in your browser; its signed-in account is managed by the browser. Profile actions require a Microsoft account in the launcher. Refresh reuses the launcher's authentication and ownership checks.
