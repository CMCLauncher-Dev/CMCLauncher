A FEW THINGS TO KNOW

Before you jump in.

Do I need to install a runtime?＋

The launcher includes .NET and the Windows App SDK. Minecraft still needs Java; you can scan for an installed runtime or download one inside the launcher.

Can I bring my existing instances?＋

Yes. Import existing Minecraft installations or supported modpack archives. Review the import options to choose how each instance is stored.

How do accounts work?＋

Microsoft sign-in verifies your Minecraft Java profile. Credentials are protected with Windows DPAPI.

Where can I get help or report a bug?＋

Visit GitHub Issues with your launcher version and the steps to reproduce the problem. Remove tokens and other private information from any logs you share.
